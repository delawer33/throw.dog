# throw.dog — правила для агентов

## ПУБЛИЧНЫЙ РЕПОЗИТОРИЙ

Этот репо открыт (github.com/delawer33/throw.dog). Всё, что коммитится,
читает весь интернет — навсегда (история не вычищается дёшево).

**Нельзя коммитить:**
- `.env`, `certs/`, любые реальные секреты, токены, пароли, ключи.
- Реальные хосты/алиасы/пути деплоя сверх того, что уже в README.
- Секреты в тестах — только очевидные фейки (`hunter2`, `change-me-…`).
- Личные данные (имейлы людей, содержимое /data/*).

**Перед пушем:** gitleaks должен быть зелёным (pre-commit хук или
`gitleaks git .`). CI гоняет его по всей истории — красный CI = не мержить.

## Код

- Язык комментариев — русский или английский, как в окружающем файле.
- Тесты: `.venv/bin/pytest` из корня репо. Все зелёные перед коммитом.
- Деплой (`./deploy.sh`) — только по явной просьбе владельца.
- Инварианты продукта (одноразовое чтение, disjoint-адреса режимов,
  ноль стороннего кода на страницах с ключом) — см. docs/CONTEXT.md и
  docs/adr/; не ломать молча.
